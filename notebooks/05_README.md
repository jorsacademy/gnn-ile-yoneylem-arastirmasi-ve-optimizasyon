# 05 — Directed GNN + Min-Cost Flow

Ana notebook: `05_directed_gnn_network_flow.ipynb`

Bu örnek, directed network flow problemlerinde yön bilgisinin GNN mesajlaşmasında korunmasının etkisini inceler. Undirected/symmetrized GNN ile incoming/outgoing mesajları ayrı işleyen directed GNN; optimal arc recall, candidate pruning, feasibility ve objective gap açısından karşılaştırılır.
