# 05 doğrulama notu

`05_directed_gnn_network_flow.ipynb` içindeki Python hücreleri sözdizimi açısından kontrol edilmiştir. Min-cost-flow instance üretimi ve SciPy `linprog` çözüm çekirdeği ayrı olarak çalıştırılmış; test edilen sentetik instance'ların feasible çözüldüğü doğrulanmıştır.

Bu çalışma ortamında `torch_geometric` kurulu olmadığı için directed/undirected GNN eğitim hücreleri uçtan uca burada çalıştırılmamıştır.
